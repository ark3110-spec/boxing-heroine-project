# ボクシングヒロイン ―花冠のリング―

ヒロインを育成し、花冠王座を目指すボクシング育成ADVです。

**[ブラウザで遊ぶ / Play in your browser](https://ark3110-spec.github.io/boxing-heroine-project/)**

- バージョン / Version: **v1.1.0**
- 日本語・英語に対応。オプションから言語・音量を変更できます。
- Japanese and English are available in Options, along with audio settings.
- マウスまたはタップで操作します。スマートフォンでも遊べます。
- Play with a mouse or touchscreen, including on a smartphone.
- 進行状況と設定は、このブラウザに保存されます。続きはCONTINUEから再開できます。
- Progress and settings are saved in your browser. Choose CONTINUE to resume.
- JavaScriptを有効にして遊んでください。 / JavaScript is required.

このリポジトリにはプレイに必要な配布ファイルを収録しています。
This repository contains the files needed to play the game.
